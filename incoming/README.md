# Új fotók ide

Töltsd fel ide a weboldal új fotóit (JPG, PNG vagy iPhone HEIC).

- Álló (portré) fotókat használj, mert a weboldal 2:3 arányra vágja őket, középre igazítva.
- Az Instagram-méretű export (1–3 MB) bőven elég, nem kell az eredeti nagy fájl.
- Feltöltés után kb. 2 percen belül a fotók automatikusan felkerülnek az oldalra, és az új sorozat lecseréli a régit. Az összes fotó lapozható, és 3 naponta más kerül előre.
